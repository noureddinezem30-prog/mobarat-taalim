# منصة مباراة التعليم — النسخة الأولية

## ما الذي يعمل في هذه النسخة؟
- موقع متجاوب بالعربية واتجاه RTL.
- تصفية الموارد حسب السلك والتخصص ونوع المورد.
- عرض بطاقات موارد تمهيدية مع نافذة قراءة.
- أسئلة تجريبية مع تصحيح فوري وتفسير.
- خطة مراجعة أسبوعية تحفظ العلامات محلياً في المتصفح.
- ملف PWA (manifest + service worker) لتمكين التثبيت من متصفح متوافق بعد النشر على HTTPS.

## الملفات
- `index.html`: واجهة الموقع والتنسيق.
- `app.js`: بيانات الموارد والأسئلة والمنطق التفاعلي.
- `manifest.json`: إعدادات تطبيق الويب القابل للتثبيت.
- `sw.js`: تخزين أساسي للملفات للعمل دون اتصال بعد أول زيارة.
- `android-wrapper/README.md`: تعليمات تحويل الموقع إلى تطبيق Android باستخدام Capacitor.
- `content/resources.json`: نسخة منظمة من بيانات الموارد الأولية.
- `content/quiz.json`: نسخة منظمة من الأسئلة التجريبية.

## تشغيل محلي
افتح `index.html` في متصفح حديث. بعض خصائص PWA والعمل دون اتصال تحتاج إلى خادم محلي أو استضافة HTTPS.

## النشر على الإنترنت
يمكن نشر المجلد على استضافة ثابتة تدعم HTTPS (مثل GitHub Pages أو Netlify أو Cloudflare Pages). ارفع محتويات هذا المجلد كما هي؛ ثم اختبر الموقع على الهاتف.

## بناء Android عبر Capacitor
راجع `android-wrapper/README.md`. يتطلب البناء النهائي تثبيت Node.js وAndroid Studio وأدوات Android SDK على حاسوبك. هذه الحزمة لا تحتوي على APK جاهز.

## ما ينقص قبل إطلاق عام موثوق؟
1. إضافة ملفات PDF وروابط امتحانات حقيقية بعد التحقق من مصدرها وحقوق إعادة النشر.
2. إرفاق التصحيحات الرسمية فقط عندما تكون منشورة رسمياً، مع وسم منفصل للتصحيحات المقترحة.
3. بناء قاعدة بيانات ولوحة إدارة للمحتوى، حسابات المستخدمين والمزامنة السحابية (غير موجودة في هذه النسخة).
4. تحديث التخصصات بحسب إعلان كل دورة رسمياً.
5. اختبار إمكانية الوصول والأمان والأداء على أجهزة متعددة.

## ملاحظة المحتوى
البيانات الحالية عينة تمهيدية وليست مكتبة كاملة، ولا تدّعي أنها امتحانات رسمية أو تصحيحات رسمية.


## مكتبة الإنترنت
أضيفت داخل الواجهة صفحة «الامتحانات والملخصات» وفهرس `content/online-sources.json` بروابط الوزارة ومصادر تجمع امتحانات وملخصات. هذا فهرس روابط وليس أرشيفاً محلياً لكل ملفات PDF؛ افتح المصدر للتحقق من الملف وحقوقه وتاريخه.
